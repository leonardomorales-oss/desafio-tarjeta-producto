# Desafío Tarjeta de Producto

Tarjeta responsive con modal y estilos BEM/Sass.

## Tecnologías

- HTML
- Sass
- Bootstrap
- BEM

## Instalación y ejecución

```bash
npm install
```

```bash
npm run sass
```

Abre `index.html` con Live Server.

## Uso

Activa el modal para ver detalles.
